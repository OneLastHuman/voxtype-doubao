声音怎么走到光标

voxtype 仍然负责录音和输入；这个项目只补上“豆包网页版”这一段。

  1. 01

    录音与预流式

    voxtype 按住热键录音。代理用 parecord 监听默认输入源，录音期间就开始上传。

    要求 voxtype 的 [audio] device = "default" 与系统默认输入源一致。

  2. 02

    本机代理

    voxtype-doubao 在 127.0.0.1:8788 提供 /v1/audio/transcriptions，用你的登录 cookie 连接豆包网页版 ASR。

    OpenAI 兼容，所以 voxtype 不需要为它改代码，只用 remote Whisper 模式。

  3. 03

    回写文本

    voxtype 拿到返回的文本，松开热键后输入到当前光标。

    文字仍然是一次性出现，不是光标级 partial。

它做什么，不做什么

不是新的输入法，也不是另一套快捷键；只是把 voxtype 的 remote Whisper 后端换成豆包网页版。

接口
POST /v1/audio/transcriptions，OpenAI 兼容
客户端
voxtype 1.1.x，[whisper] mode = "remote"
凭证
豆包网页版登录 cookie；WebKit 窗口保存，或从 doubao-murmur 导入
预流式
默认开启；录音时上传，松开后返回
输出
松开后一次性写入；不是光标级 partial
网络
只监听 127.0.0.1:8788
服务
systemd 用户服务 voxtype-doubao.service

四步接通

从 clone 到第一次听写。命令默认在仓库根目录执行。

1

安装

Arch / Omarchy

安装脚本会创建 .venv 并安装依赖。

bash
git clone https://github.com/OneLastHuman/voxtype-doubao.git
cd voxtype-doubao
./scripts/install.sh
2

登录豆包

cookie

在打开的豆包页面登录，等页面加载完，点右上角“保存登录”。

bash
.venv/bin/voxtype-doubao login
3

把 voxtype 指向代理

remote whisper

在 ~/.config/voxtype/config.toml 里使用 remote 模式，然后重启 voxtype。

toml
[whisper]
mode = "remote"
remote_endpoint = "http://127.0.0.1:8788"
remote_model = "doubao-web-asr"
remote_timeout_secs = 60
bash
systemctl --user restart voxtype
4

启动代理

systemd user

安装并启动用户服务，然后确认状态。

bash
.venv/bin/voxtype-doubao install-service
.venv/bin/voxtype-doubao status

日志：journalctl --user -u voxtype-doubao -f

更多选项

手动安装

bash
python3 -m venv --system-site-packages .venv
.venv/bin/pip install -e .

已有 doubao-murmur 凭证

bash
.venv/bin/voxtype-doubao import

关闭预流式

如果不需要录音期间上传，可以关闭：

bash
.venv/bin/voxtype-doubao install-service --no-prestream

或设置环境变量 DOUBAO_PRESTREAM=0。
